# OpenOrbis: provoking-last apos GS

Fonte para template OpenOrbis com GnmDriver e libkernel. Emite tres vertices com atributos distintos e compara provoking-last com a mesma primitiva rotacionada usando provoking-first. Confere hashes de fill, point fill, wireframe largo e stipple e uma execucao do GS.

Validacao local somente sintatica. Nao cobre tessellation, clipping por viewport ou todas as regras de cobertura/interpolacao.
